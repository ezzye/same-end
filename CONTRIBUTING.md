# Contributing

Keep changes focused on private, small-group viewing and document what has actually been tested. Do not add public room discovery, analytics, default telemetry, or invite secrets to the repository.

Before opening a change, check that it contains no credentials, private invitation links, personal data, local machine paths, captured media, build output, or downloaded desktop runtimes. Do not commit `.env` files or real cast links. Keep third-party license notices next to vendored code.

Use only media you are authorized to capture and share. Do not add DRM circumvention or instructions for bypassing a publisher's access controls. Report browser, operating system, network setup, and exact scenario when describing test results; distinguish a local check from cross-network or physical-device validation.
