Keep Same End handy

Watch and chat on your phone. A computer shares the match.

iPhone & iPad

  1. Open Same End in Safari.
  2. Tap Share (sometimes inside the page menu).
  3. Choose Add to Home Screen, then Add. Leave Open as Web App on if shown.

Can’t see it? Scroll down the share sheet or choose Edit Actions.

Apple’s guide ↗

Android

  1. Open Same End in Chrome.
  2. Open the ⋮ menu beside the address bar.
  3. Choose Install app or Add to Home screen, then confirm. Some versions say Install and create shortcut.
Google’s guide ↗

Use your browser’s Install app option. In Safari on newer Macs, use File → Add to Dock.

Installation is optional. Keep your invitation and open it again to rejoin your room.
