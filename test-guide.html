First test: two laptops

  1. Both open Same End in Chrome or Edge. Begin on the same Wi-Fi, then try different homes.
  2. The person starting the cast chooses 10 seconds · connection test, then Try the test picture.
  3. Choose Make invitation, then Copy invitation. Send that link privately to your friend. If copying is blocked, select and copy the invitation shown on screen.
  4. Your friend opens the complete invitation in their browser. Joining starts automatically. Keep both pages open; no reply file, login or password is needed.
  5. Watch the player in Same End. Compare the moving test picture and clock. Add another friend using the same invitation if you wish.
  6. Choose End / leave cast when finished. A new cast has a new invitation.

Then try your own source

Start a new cast with the normal 5 minutes · group standard delay. Choose Share a tab or screen and select what to share in your browser’s picker. Include tab audio if offered.

Make and send its new invitation. Everyone, including the caster, watches the delayed Same End player. The original captured screen is still live. Each viewer may need to select Turn sound on.

Share a source you are entitled to capture and share. Protected video may appear black or refuse capture.

If joining stalls

Keep the caster’s page open and awake. Check that the invitation is complete and belongs to the current cast. Leave and reopen the invitation once. Try the same Wi-Fi and then another network if necessary.

Some VPNs, routers and firewalls prevent direct connections. There is no fallback server carrying video. The public connection service can also be unavailable.

Keep the group private

Send invitations only to people you trust. Anyone with the complete invitation can attempt to join. There is no individual approval or removal list. End the cast and create a new one if an invitation escapes the group. Peers can see network addresses and can retain received material.

What the tests establish

The prototype has passed separate Chrome sessions on one Mac, including an actual viewer relay, shared timing, invitation handling, stop propagation and offline app reopening. A prior full five-minute wait was checked. These tests do not establish performance in your homes.

Mac and Windows laptops with Chrome or Edge are the intended first trial. A physical Windows machine, phone viewing and full-match reliability still need testing. Keep laptops awake and the app open. Installing the PWA does not remove those limits.

Video uses the group’s computers and broadband. The website host serves the small app; a public tracker introduces peers. Neither is a video-hosting service.
